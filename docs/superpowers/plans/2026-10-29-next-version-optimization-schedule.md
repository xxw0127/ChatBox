# ChatBox 下一版本优化日程

日期：2026-10-29
当前版本：0.4.1（已上线）

## 0.4.2 — 体验补丁（10/30–10/31）

优先处理这轮暴露出来、成本低但影响直接的问题：

1. **搜索入口**
   - 聊天标题右侧加放大镜按钮，点击直接打开消息搜索。
   - 保留 `Ctrl+F` 和右侧栏“搜索消息”输入框。
2. **群未读角标**
   - 未读数从群名标题里移出，改成独立小角标，不占标题文字。
3. **缩略图缓存失效**
   - 缓存 key 加版本；旧的 320×180 缩略图自动删除并重新拉取 640px 版本。
   - 解决其他机器仍看到旧糊图的问题。
4. **更新证书兜底**
   - CA 证书嵌入 qrc；`certs/ca.crt` 缺失时使用内置证书。
   - 更新失败日志记录版本、证书路径和 Qt TLS 状态，便于定位。
5. **高 DPI / 深色主题**
   - 125%/150% 缩放下检查新图标、按钮、标题和右侧栏宽度。
   - 深色主题下三条杠、侧栏状态图标、未读角标对比度检查。
6. **生产构建树修复**
   - 当前生产 `/home/ubuntu/chatbox` 源码树缺 `server/file`，这次是临时用完整源码构建的。
   - 部署改为从仓库完整源码构建，避免再次出现“构建产物少模块”的风险。

验收：客户端测试全绿；干净 Windows 机器验证 TLS、文件传输、更新；0.4.2 包、feed、回滚备份齐全。

## 0.5.0 — 多设备与 Android 底座（11/1–11/7）

按已有 `2026-10-29-chatbox-multidevice-server.md` 的 12 个任务推进：

- 服务端 `user_id → 多个 SessionBinding` 多设备会话。
- 按会话游标同步、已读同步、私聊回显。
- 群/私聊/好友/资料/文件通知 fan-out 到该用户全部设备。
- 桌面端离线游标、已读/回显、设备管理页。
- 旧 0.4.x 客户端兼容；迁移脚本可重复执行；协议只追加。

验收：任务测试 + 双设备联调 + 旧客户端回归 + 服务端部署/回滚演练。

## 0.5.1 — 媒体与搜索体验（11/8–11/9）

- 图片查看器：上一张/下一张、缩放、圆角缩略图。
- 视频：内置播放或首帧+播放器；旧视频缩略图重新生成。
- 搜索：搜索历史、结果关键词高亮、无结果空状态。
- 左侧栏折叠/展开（如果确认需要）。

## 0.6.0 — 交付与运维硬化（11/10–11/12）

- 干净 Windows 机器 CI：不预装 Qt/OpenSSL，验证 TLS、文件传输、自动更新。
- 一键部署/回滚脚本、健康检查、构建产物 SHA-256 校验。
- 代码签名/安装包、MySQL 备份恢复演练。
- 性能与可访问性：长历史滚动、缩略图加载、键盘导航、对比度。

## 风险与顺序

- 0.5.0 多设备是主线，工作量大；如果时间紧，0.5.1 顺延到 0.5.0 之后。
- 0.3.2 旧客户端无法自助更新，只能手动装 0.4.x；0.4.2 的 CA 兜底和文档用于降低再次发生的概率。
- 0.4.2 的生产构建树修复要放在发布前，否则下一次部署仍有缺模块风险。
