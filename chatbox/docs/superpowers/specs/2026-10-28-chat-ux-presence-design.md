# ChatBox 聊天体验与在线状态设计

日期：2026-10-28

状态：已确认（2026-10-28）

## 1. 背景与范围

本轮修 6 个体验问题，按已确认的分工执行：

| # | 需求 | 本线处理 |
|---|---|---|
| 1 | 消息显示头像与 ID | 完整实现 |
| 2 | 输入 `@` 弹出成员面板；可提及离线成员 | 面板与交互完整实现；离线成员数据源等群组线的持久成员表 |
| 3 | 气泡文字垂直居中 | 完整实现 |
| 4 | 搜索结果跳转并定位原文 | 完整实现（在线 + 离线） |
| 5 | 删除气泡旁悬浮的「回复 / 撤回」条 | 完整实现，右键菜单保留 |
| 6 | 在线状态实时更新 | 完整实现（新增 presence 推送） |

非目标：

- 不做持久群成员表、群组、群文件、右侧栏改版（第一条工作线负责）。
- 不改数据库 schema；不改消息帧的既有字段顺序。
- 不做「离线被 @ 的收件箱」；离线 mention 的提醒依赖群组线的未读体系。

## 2. 目标行为

### 2.1 消息头像与 ID

- 每条消息在气泡外侧显示 36px 圆形头像：对方在左，自己在右。
- 对方消息在气泡上方显示 `昵称` + `U00001001`（`publicUserId()` 格式）两段小字；
  自己消息不显示昵称/ID（避免重复）。
- 昵称 + ID 行沿用现有 `shouldShowSenderName` 分组（发送者变化或间隔 3 分钟），
  不在每条消息上重复；房间与私聊都显示，私聊同样带 ID。
- 头像来源：`AvatarCache` 中的服务端头像；没有时用 `fallbackAvatar(昵称, user_id, 36)`。
  渲染后对缓存里没有的发送者发起 `requestPeerAvatar()`，头像到达后只重绘当前会话。
- 头像以 `QTextDocument::ImageResource` 注入，URL 形如
  `chatbox-avatar://<user_id>?v=<version|fallback>`；`ChatView` 在 `setHtml()` /
  `insertHtml()` 之前注册资源，避免 Qt 先绘制成破图。
- 撤回消息保留头像，不显示昵称/ID（沿用现有「撤回不显示发送者」规则）。
- `ChatView` 查找气泡表格时改为「外层表格 → 最内层表格」，以兼容头像列；
  消息区间映射、右键菜单、圆角遮罩的行为保持不变。

### 2.2 `@` 提及面板

- 仅在房间会话生效；私聊不弹面板（沿用现状）。
- 触发：输入框里键入 `@`（位于行首或空白之后）立即在光标上方弹出面板；
  继续输入 `@` 后面的字符会实时过滤。
- 面板实现为聊天页的子控件（`QFrame`，无边框、`Qt::NoFocus`、
  `WA_ShowWithoutActivating`），而不是 `Qt::Popup` 顶层窗口：
  弹出后输入框必须继续保有键盘焦点，才能边输入边过滤。
- 面板内容：
  - 第一项固定为「所有人」，插入 `@所有人 `。
  - 之后是当前成员列表（排除自己），每行显示头像、昵称、`U00001001`、在线圆点。
  - 数据源当前是 `member_list_`（在线成员）；群组线落地持久成员表后，
    只需替换候选来源，面板不重写。
- 过滤：按昵称或 ID 前缀/包含匹配，忽略大小写；无匹配时显示「没有匹配的成员」。
- 键盘：`↑ / ↓` 移动，`Enter / Tab` 选中，`Esc` 关闭；鼠标单击选中；
  点击面板外关闭。面板打开时 `Enter` 不再发送消息。
- 插入：把光标前已输入的 `@查询词` 整段替换为 `@昵称 `，光标落在末尾。
- `@` 按钮复用同一面板（空查询），不再弹 `QMenu`。
- `@所有人` 视为提及所有人：客户端收到含 `@所有人` 的房间消息时也走 mention 提醒。

### 2.3 气泡文字垂直居中

- 现状：正文 `line-height: 150%` 会在最后一行下方留下空白；实测单行气泡
  文字到气泡上/下边缘为 17px / 25px（100% 时 17px / 15px），确实偏上。
- 修改：正文行高改为 110%，气泡内边距保持上下对称（12px），
  时间/状态行仍留在气泡外。
- 验收：单行、多行、含引用三种气泡，文字像素到气泡上/下边缘的距离差 ≤ 1px
  （渲染成图后按暗色像素边界测量，并保存截图核对）。

### 2.4 搜索跳转与高亮

- 搜索结果单击即跳转（双击/回车同样有效）。
- 目标消息已在当前 `MessageStore` 中：直接滚动定位，不发请求，不进入定位模式。
- 不在内存中：
  - 在线：发 `HISTORY`，`before_id = message_id + 1`，`limit = 50`；
    响应按「替换当前页」处理。服务端语义是 `id < before_id` 的最近 50 条，
    所以目标消息固定是页内最新一条，**位于页底**，其上方是 49 条更早的上下文。
  - 离线：`HistoryStore::before(context, target, message_id + 1, 50)`。
- 定位模式（jump mode）：
  - 进入条件：目标不在当前页，需要换页。
  - 页面底部右侧浮出「回到最新 ↓」按钮；点击后请求最新一页（`before_id = 0`）
    并退出定位模式。
  - 定位模式下，当前会话的新消息只入库、不追加到可见页，也不发已读回执；
    「回到最新」后按最新一页重建，不会出现中间断档。
  - 定位模式下发送消息：先退出定位模式（在线请求最新页、离线读本地最近一页），
    再把待发消息插入页尾；`replaceHistory` 会保留未确认消息。
  - 切换会话/断线自动退出定位模式。
- 定位：滚动到底部，使目标气泡完整可见（不强行居中），叠加 1.8 秒高亮，
  随后淡出。高亮绘制在 `BubbleOverlay` 中，不修改文档内容。
- 目标不存在（已删除/超出服务端保留范围）：状态栏提示「消息不存在」，
  并退出定位模式。
- 跳转成功后关闭搜索对话框。
- 搜索框仍只搜索当前会话（与现状一致）；切换会话时关闭并清空搜索对话框，
  避免旧结果在新会话里跳到同号的无关消息。

### 2.5 删除悬浮操作条

- 删除 `MessageActionBar`（头/源文件、资源引用、测试引用）以及
  `ChatView` 的 hover 状态与 `hoveredMessage / hoverCleared` 信号。
- 气泡右键菜单保留：重发、回复、撤回、复制（有选区时复制选中）。
- 移除后不再有「气泡旁两个难点的小胶囊」。

### 2.6 在线状态实时更新

协议新增一条推送（追加在 `0x00A4`，避开群组线的 `0x00B0–0x00CF`）：

```text
PRESENCE_PUSH (0x00A4)
  u16 count
  count × { u64 user_id, u8 online, u64 seq }
```

`seq` 由 `SessionManager` 在绑定/解绑的同一把锁内递增（全局原子计数即可），
用于客户端丢弃乱序到达的旧事件（只应用 `seq` 更大的那条）。

服务端：

- 触发点：
  - 登录/恢复会话成功 → online=1；
  - 主动登出 → online=0；
  - 连接关闭 / 心跳超时 → online=0；
  - 顶号（resume takeover / 新登录踢旧连接）不产生 offline：
    `unbind` 只在 `connection_id` 匹配时移除绑定并返回 user_id，
    被顶掉的旧连接解绑时匹配不到新绑定，直接返回 0。
- 接收者：所有已认证会话，排除事件本人当前连接。理由：项目是公开聊天室，
  在线状态不敏感；登录/登出是低频事件，O(N) 广播可接受，且避免在 IO 线程查库。
- `SessionManager` 增加 `snapshot()`（连接 id + io 线程 id）；
  `unbindByConnection()` 改为返回「确实被移除的 user_id」，未移除返回 0，
  以保证顶号不会误报离线。
- 广播按 io 线程分组后 `postMulticast()`；与现有房间成员快照广播同一机制。
- 旧客户端收到未知命令走 `default: break`，不受影响。

客户端：

- 新增 `presence_overrides_`（user_id → online）与 `presence_seq_`（user_id → seq）；
  同一状态重复到达或 `seq` 更旧时跳过刷新。
- 在好友列表、会话列表、资料弹窗应用；列表响应到达时用 `presence_overrides_`
  覆盖响应里的 online 字段，避免「推送先到、列表后到」把新状态覆盖回旧值。
- 房间成员列表继续由现有 `ROOM_MEMBERS` 快照维护（含掉线推送），
  presence 推送不直接改成员行，避免两种数据源打架。
- 断线/进入离线模式时清空覆盖表与序号：重连后的好友/会话列表是权威快照，
  不能让断线前的旧在线状态覆盖它。登出/清理会话时同样清空。

## 3. 客户端结构改动

新增：

- `core/mention_query.{h,cpp}`：`mentionTokenAt(text, cursor, &start, &query)`，
  纯函数，负责识别光标前的 `@` 片段，便于单测。
- `ui/mention_popup.{h,cpp}`：聊天页子控件 `QFrame`（无边框、`Qt::NoFocus`、
  `WA_ShowWithoutActivating`）+ 列表，负责候选展示、过滤、键盘导航、
  发出 `mentionChosen(user_id, name)`。
- `ui/mention_item_delegate.{h,cpp}`：头像、昵称、ID、在线点（复用
  `fallbackAvatarBackground` / `readableForeground`，与好友列表视觉一致）。

修改：

- `core/message_renderer.*`：头像列、昵称 + ID、行高与内边距。
- `ui/chat_view.*`：头像资源注入、气泡表格查找、跳转高亮、删除 hover 逻辑。
- `ui/main_window*.cpp`：presence 应用、@ 面板接线、搜索跳转与定位模式、
  「回到最新」按钮、删除操作条接线。
- `ui/message_search_dialog.*`：结果单击/回车发出跳转信号。
- `ui/message_input.*`：不新增状态，仅由面板事件过滤器拦截按键。

删除：

- `ui/message_action_bar.{h,cpp}` 及 `tests.pro` / `chatbox.pro` 中的引用。

## 4. 边界与错误处理

- 头像请求失败/无头像：一直使用首字母头像，不阻塞消息渲染。
- 头像到达时用户已切换会话：只重绘当前会话，不为后台会话重建文档。
- `@` 面板打开时切换会话/断线：立即关闭；断线时输入框禁用，面板不可用。
- 过滤后无结果：保留面板，显示空状态，`Enter` 不插入。
- 搜索跳转请求超时：复用现有 8 秒搜索超时提示；跳转态复位。
- 跳转页与当前未读/滚动状态：跳转按「替换当前页」处理，不合并旧页。
- presence 推送里出现未知用户：只记录覆盖表，不创建 UI 行。
- 同一用户连续快速上下线：按 `seq` 只应用最新一条，乱序到达的旧事件丢弃。

## 6. 兼容性

- 协议：只新增命令与推送，既有字段顺序不变；旧客户端忽略未知命令。
- 数据：不改 MySQL schema、不改本地 SQLite schema。
- 与群组线：`@` 面板候选来源、搜索跳转入口都做成小接口；
  群组线落地后替换数据源即可，不需要重写本线的 UI 与定位逻辑。
